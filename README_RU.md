# Pocket Arena 3DS — прототип 0.1

Неофициальный офлайн homebrew-баттлер для обычной Nintendo 3DS/2DS
и New 3DS. Это самостоятельная упрощённая игра, не порт Pokemon Showdown.
Не содержит ROM, спрайты, музыку, ключи или SDK Nintendo.
Названия Pokemon принадлежат соответствующим правообладателям.

## ВАЖНО: что находится в архиве

В архиве **исходный код**, Makefile, тесты и GitHub Actions workflow.
Готового `pocket-arena.3dsx` НЕТ: ARM-сборка и запуск на настоящей 3DS
в этой среде не выполнены. Успех сборки на devkitPro ещё нужно подтвердить.
Не копируй этот ZIP в Homebrew Launcher в ожидании запуска.
Проверена переносимая боевая логика на Linux/GCC и размещение текста
в макетах экранов; это не тестирование эмулятором или консолью.

## Что реализовано

- Бои 1 на 1: Pikachu, Charmander, Squirtle, Bulbasaur, Sandshrew, Eevee.
- По 4 приёма, PP, попадание/промах, сила, типы, скорость и STAB x1.5.
- Recover восстанавливает половину максимального HP; Guard действует
  с приоритетом и уменьшает урон вдвое в текущем ходу.
- Когда все PP закончились, используется Struggle с отдачей.
- Easy: случайный доступный приём.
- Normal: оценка ожидаемого урона и лечения.
- Hard: дополнительно учитывает вероятность добивания и угрозу ответного
  удара при лечении. Это эвристика, не нейросеть и не поиск по дереву ходов.
- ИИ выбирает действие до исполнения хода игрока и не читает его выбор.
- Локальный рейтинг: старт 1000, Elo-подобная формула с K=32.
  Рейтинги ботов фиксированы: Easy 800, Normal 1100, Hard 1400.
  Это игровая шкала, а не откалиброванный рейтинг мастерства.
- Ничья не меняет рейтинг; сдача считается поражением.
- Предел боя 200 ходов, затем ничья.
- Запись профиля после боя и при выходе; резервная копия предыдущего
  сохранения. Защита от внезапного отключения питания не гарантируется.

## Ограничения

Текстовый интерфейс на английском, без спрайтов, анимации и звука.
Русская инструкция есть здесь, кириллицу в консольный интерфейс не добавляли.
Только один тип на покемона. Упрощённые характеристики и урон.
Нет категорий physical/special, статусов, предметов, способностей,
критических попаданий, IV/EV, команд, смен, онлайна или импорта Showdown.
Типовая таблица ограничена шестью используемыми типами.
Баланс ещё не проверен на реальных игроках.

## Сборка на Windows (официальный devkitPro)

1. Открой https://devkitpro.org/wiki/Getting_Started и следуй разделу Windows.
   Установщик: https://github.com/devkitPro/installer/releases/latest
   Выбери инструменты разработки для 3DS/devkitARM.
2. Открой терминал **devkitPro MSYS/MSYS2**, а не обычный cmd/PowerShell.
3. При необходимости установи набор для 3DS:

   ```sh
   pacman -S --needed 3ds-dev
   ```

   Если вопрос об установке группы — выбери все пакеты.
4. Распакуй проект, например, в `C:\3dsdev\pocket-arena-3ds`.
   Желательно без пробелов и кириллицы в пути.
5. В терминале devkitPro:

   ```sh
   cd /c/3dsdev/pocket-arena-3ds
   make -j2
   ```

   В корне проекта должен появиться `pocket-arena.3dsx`.
   Если DEVKITARM не определён, проверь установку devkitARM
   и перезапусти терминал devkitPro.

## Альтернативная сборка через GitHub (без установки компилятора на Windows)

Workflow уже находится в `.github/workflows/build.yml`.
Нужен аккаунт GitHub и собственный репозиторий с включёнными Actions.

1. Создай репозиторий и добавь в его корень **содержимое** папки проекта.
   Проверь наличие `.github/workflows/build.yml` (скрытая папка тоже нужна).
2. Открой вкладку Actions → Build 3DS homebrew → Run workflow.
3. Дождись зелёного результата и скачай artifact `pocket-arena-3dsx`.
4. Распакуй artifact: внутри должен быть `pocket-arena.3dsx`.

Workflow использует контейнер `devkitpro/devkitarm:latest` и действия GitHub.
Он подготовлен, но здесь не запускался. Если сборка завершится ошибкой,
пришли текст ошибки — его нужно исправить, а не переименовывать ZIP в .3dsx.
Для закрытого репозитория проверь доступные лимиты Actions в своём тарифе.

## Запуск на 3DS с установленным homebrew

1. Выключи консоль перед извлечением SD-карты. Сделай копию важных данных SD.
2. Создай папку `SD:/3ds/pocket-arena/`.
3. Скопируй **собранный** `pocket-arena.3dsx` в эту папку.
4. Верни SD в консоль, включи её и запусти Homebrew Launcher привычным
   для твоей установленной системы способом.
5. Выбери приложение; оно может отображаться по имени файла без иконки.

Это `.3dsx` для Homebrew Launcher, не `.cia` для установки в HOME Menu.
Обновлять или переустанавливать Luma для этого проекта не требуется.

## Управление

В меню:
- Вверх/вниз — покемон.
- Влево/вправо — сложность.
- A — начать бой со случайным соперником.

В бою:
- Вверх/вниз — выбор приёма, A — ход.
- X — немедленно сдаться, это поражение. Подтверждения пока нет.
- START — сдаться, сохранить и выйти.

После боя: A — в меню, START — выйти.
При ошибке сохранения: START — повторить, B — выйти без повторной записи.
При принудительном закрытии/отключении питания текущий бой не сохраняется.

Профиль: `SD:/3ds/pocket-arena/profile.txt`.
Резервная копия: `profile.txt.bak`.
Для сброса рейтинга при выключенной консоли удали оба файла.

## Тесты движка (не сборка игры для 3DS)

Нужен обычный GCC с поддержкой C11, например, в Linux:

```sh
gcc -std=c11 -Wall -Wextra -Werror -Iinclude source/battle.c tests/test_battle.c -lm -o test-battle
./test-battle
```

Выполнены 4320 симуляций: все 36 пар, 3 сложности, 40 начальных seed.
Дополнительно проверены иммунитет, эффективность, PP, добивание,
приоритет Guard, лечение, Struggle, рейтинг и запись/чтение/резерв профиля.
Результат запуска — в TEST-RESULTS.txt.
